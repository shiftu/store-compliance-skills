### Android developer verification

By making Android safer, we're protecting an environment for developers and users to confidently create and connect. This extra layer of security helps deter bad actors and makes it harder for them to repeatedly spread harm.

**Effective September 30, 2026**

Protections begin for users installing apps from [participating stores](/developer-verification/guides#locations) in select regions on [certified Android devices](/developer-verification/guides/faq#versions). We'll continue rolling out user protections globally in 2027.
